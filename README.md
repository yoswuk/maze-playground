# 미로 놀이터

아이를 위한 A4 인쇄용 미로 활동지 생성기입니다. 브라우저에서 바로 동작하며 별도의 서버나 데이터베이스가 필요하지 않습니다.

## 기능

- 쉬움(12×12), 보통(18×18), 어려움(24×24), 매우 어려움(30×30)
- 출발은 왼쪽 외곽, 도착은 오른쪽 외곽
- A4 한 장에 미로 1개
- 모바일 화면과 터치 조작 최적화
- 정답 보기 및 정답지 인쇄
- 숫자로 원하는 개수를 입력해 여러 미로를 한 번에 인쇄
- 브라우저 인쇄 화면에서 프린터 출력 또는 PDF 저장
- 여러 후보 중 정답 경로의 우회도, 회전, 갈림길, 가짜 길의 깊이를 함께 평가해 난이도별로 품질이 좋은 미로를 선택

## 미로 생성 방식

각 미로는 Growing Tree 방식으로 모든 칸이 연결되고 정답이 하나뿐인 완전 미로로 생성됩니다. 같은 시드에서 여러 후보를 만든 다음 아래 요소를 함께 평가합니다.

- 최단 직행 경로에 비해 정답 경로가 얼마나 우회하는지
- 정답 경로에서 실제로 선택해야 하는 갈림길의 밀도
- 잘못 들어간 가지 길의 평균 깊이와 도착점 근처의 함정 깊이
- 막다른 길의 비율, 회전 비율, 가장 긴 직선 구간

따라서 격자 크기뿐 아니라 풀이 과정의 복잡성도 쉬움부터 매우 어려움까지 단계적으로 달라집니다.

## GitHub Pages

저장소의 `main` 브랜치 루트를 Pages 게시 소스로 선택하면 됩니다.

1. **Settings → Pages**로 이동합니다.
2. **Build and deployment → Source**에서 **Deploy from a branch**를 선택합니다.
3. Branch는 `main`, 폴더는 `/(root)`를 선택하고 저장합니다.

## 로컬 실행

정적 파일이므로 `index.html`을 직접 열거나 간단한 HTTP 서버로 실행할 수 있습니다.

```bash
python3 -m http.server 8000
```
